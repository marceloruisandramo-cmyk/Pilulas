Como Adicionar um Novo Artigo (Passo a Passo)

  1. Abra a página /admin/novo-artigo.html;
  2. Preencha os campos (Título, Categoria, Jurisdição, Conteúdo, Fontes);
  3. Clique no botão GERAR ARTIGO HTML;
  4. Baixe o arquivo gerado (ex: meu-novo-artigo.html);
  5. Coloque o arquivo baixado dentro da pasta /artigos/ do projeto;
  6. (Opcional) Adicione o card do artigo na página artigos.html;
  7. (Opcional) Adicione o objeto do artigo na lista do js/app.js para busca instantânea;
  8. Faça o git commit e git push no GitHub;
  9. O Cloudflare Pages publica o artigo automaticamente em menos de 10 segundos!
