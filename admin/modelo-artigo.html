Estrutura Canônica de um Artigo Estático

Guia de referência detalhando cada componente semântico exigido em cada página de artigo na pasta /artigos/.

Para garantir que o portal permaneça veloz, acessível e sem quebra de links após deploy no Cloudflare Pages, todo arquivo dentro de /artigos/ segue rigidamente os padrões abaixo:

1. Caminhos Relativos Universais

Como os artigos ficam dentro da pasta /artigos/, todos os links para a raiz utilizam ../:

  • Folha de estilos: <link rel="stylesheet" href="../css/style.css">
  • Script local: <script src="../js/app.js"></script>
  • Logotipo: <img src="../imagens/logo.svg" ...>
  • Link da home: <a href="../index.html">

2. Elementos Semânticos Obrigatórios

  1. Cabeçalho do Artigo (<header class="article-header">): Breadcrumbs, H1, lead explicativo e barra com metadados (categoria, jurisdição, data, autor e tempo de leitura estimado).
  2. Corpo Editorial (<section class="article-body">): Parágrafos <p>, subtítulos <h2>, citações em destaque <blockquote> e listas <ul> ou <ol>.
  3. Caixa de Fontes (<section class="sources-box">): Onde constam as fontes históricas e referências documentais primárias.
  4. Aviso Jurídico Obrigatório (<div class="disclaimer-card">): O texto estatutário avisando que o portal não constitui consultoria jurídica.
  5. Artigos Relacionados (<section class="related-articles">): Dois cartões com links para outras pílulas do portal.

3. Código-Fonte Boilerplate Copiável

Se preferir criar manualmente um artigo sem usar o gerador automático, use a base abaixo:

<!DOCTYPE html>
<html lang="pt">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Título do Artigo — Pílulas Jurídicas</title>
  <meta name="description" content="Descrição resumida para mecanismos de busca.">
  <link rel="stylesheet" href="../css/style.css">
</head>
<body>
  <div class="legal-alert-bar">Pílulas Jurídicas • Conhecimento e História do Direito</div>

  <header class="site-header">
    <div class="container header-inner">
      <a href="../index.html" class="brand-link">
        <img src="../imagens/logo.svg" alt="Pílulas Jurídicas" class="brand-logo" width="34" height="34">
        <span class="brand-title">Pílulas Jurídicas</span>
      </a>
    </div>
  </header>

  <main class="main-content">
    <div class="container reading-container">
      <article>
        <header class="article-header">
          <h1 class="article-title">Título da Pílula Jurídica</h1>
          <p class="article-lead">Resumo conceitual da pílula jurídica em destaque.</p>
        </header>
        <section class="article-body">
          <p>Texto factual do artigo devidamente documentado.</p>
        </section>
        <div class="disclaimer-card">
          <strong>Aviso Jurídico:</strong> Este site possui finalidade exclusivamente informativa e educativa.
        </div>
      </article>
    </div>
  </main>
  <script src="../js/app.js"></script>
</body>
</html>
